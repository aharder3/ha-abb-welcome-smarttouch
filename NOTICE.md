# Notices and credits

This repository is based on and extends:

https://github.com/rankjie/ha-abb-welcome

The upstream project and its contributors implemented the majority of the
original ABB Welcome Home Assistant integration, including the foundations for
MyBuildings communication, provisioning, SIP signalling, RTP media handling,
Home Assistant entities and go2rtc/WebRTC support.

This fork adds generic ABB / Busch-Jaeger SmartTouch support.

SmartTouch devices are discovered through ABB MyBuildings as:

    com.abb.ispf.client.welcome.panel
